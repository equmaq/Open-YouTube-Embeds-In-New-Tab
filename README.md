# Open-YouTube-Embeds-In-New-Tab
A userscript that turns YouTube embeds into direct links opening in a new tab

## Why?
Simple! Because YouTube is evil and fucks up your embeds if you use an ad-blocker and a VPN (or something like that).  
You used to be able to right click the embed after attempting to play it and copy the link, but that got removed a while back. So i made this!

## What it do?
Replaces YouTube embeds with a link that opens in a new tab, while preserving the thumbnail.

## Installation
You'll need a [userscript manager](https://en.wikipedia.org/wiki/Userscript_manager) browser extension, i recommend [Tampermonkey](https://www.tampermonkey.net/). 

Install if from [Greasyfork](https://greasyfork.org/en/scripts/595398-open-youtube-embeds-in-new-tab/code) (recommended)  
Or manually copy and paste the raw code from [Github](https://raw.githubusercontent.com/equmaq/Open-YouTube-Embeds-In-New-Tab/refs/heads/main/OYEINT-user.js)
